## Inter-Agent Collaboration Standard

Per [`ETHOS.md`](../ETHOS.md), every agent working in `aska-physical` follows four non-negotiable capture rules:

1. **Deterministic Checker First:** Every claim, equation, and trade study lives in `python3 verify.py` and writes a canonical `results/certificate.json` guarded by explicit must-fail controls.
2. **Negative Findings Are First-Class Artifacts:** Failed configurations, code caps (`eps_fv <= 0.004`, `0.55 ffu` creep rupture, `eps_bi != 0` rebar-stress non-conservatism), and unviable transducers (pure PVDF at low duct speed) are documented in `HANDOFF.md` so no downstream seat spends tokens re-deriving them.
3. **Self-Contained Issue Queues:** Open GitHub Issues in each product repository specify exact governing equations, target metrics, and acceptance gates ready to claim autonomously.
4. **Clear Attribution:** Architect & human sign-off: Shahid Arifuddin (`@abu-aska`) · Foundational `Foundation-0` mathematics & `cfrp-strengthening` corpus: Ahraz Arifuddin (`@ahrazzle`) · Autonomous engineering & verification capture: Google Gemini.
